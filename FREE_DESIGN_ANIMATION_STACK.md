# 100% free design + animation + graphics stack for high-quality websites
All items below are free for commercial use (MIT / Apache / OFL / CC0 / free tier with no watermark). Verified licenses noted.

## 1. Animation (code)
| Tool | What it does | License | Best use |
|---|---|---|---|
| **Motion** (`motion`, ex-Framer Motion) | Declarative React animations, layout/shared-element, gestures, scroll | MIT | Page/component motion in React/Next |
| **GSAP** (incl. ScrollTrigger, SplitText, MorphSVG — all plugins free since 2025) | Timeline-based pro animation, scroll choreography, text splitting | Free (Webflow "no-charge" license, commercial OK) | Hero sequences, scroll stories, SVG morph |
| **Lenis** | Buttery smooth scrolling | MIT | Pair with GSAP ScrollTrigger |
| **Auto Animate** (`@formkit/auto-animate`) | One-line list/DOM transitions | MIT | Lists, filters, reorder |
| **Lottie** (`lottie-react`) + **LottieFiles free library** | Vector animations from After Effects | MIT (player) / CC-BY or free assets | Icons, empty states, onboarding |
| **Rive** (runtime free, editor free tier) | Interactive state-machine animations | MIT runtime | Animated icons, mascots, buttons |
| **tsParticles** | Particles, confetti, backgrounds | MIT | Celebrations, hero backgrounds |
| **View Transitions API** (native) + Next `react-view-transitions` | Page transitions without JS libs | Web standard | Route transitions |
| **Theatre.js** | Visual timeline editor for Three.js/DOM | Apache-2.0 | Cinematic sequences |
| **Anime.js v4** | Lightweight timeline/SVG/stagger | MIT | Small sites, SVG line draw |
